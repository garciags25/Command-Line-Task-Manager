# Command-Line Task Manager

A Java command-line application for creating and managing tasks through a simple text-based interface.

## Project Status

🚧 **In Development**

This project is currently being developed. Additional task management features and improvements are planned.

## Features

* Create and manage tasks
* Track task status
* Store task descriptions
* Record task creation and update times
* Command-line interface

## Technologies

* Java
* Object-Oriented Programming
* Enums
* `LocalDateTime`

## Task Structure

Each task contains:

* Task ID
* Description
* Status
* Creation date and time
* Last updated date and time

Task statuses include:

* `TODO`
* `IN_PROGRESS`
* `DONE`
